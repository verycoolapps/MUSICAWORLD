# Cinematic Composition Reference

Load for film scores, trailers, scene music, and any narrative-scored work.

## The Cue Workflow

Before writing a note, establish (in this order):

1. **Narrative situation** — what is happening, what changed?
2. **Character POV** — whose emotion are we inside?
3. **Emotional intention** — one sentence, e.g. "dread with reluctant hope."
4. **Scene duration & hit points** — where must music land (cuts, reveals)?
5. **Intensity arc** — e.g. 2→5→9→4 on a 1–10 scale.
6. **Instrumentation palette** — lean (3–6 core colors) + accent.
7. **Signature motif** — the DNA of this score.
8. **Climax & ending** — resolve or deliberately withhold.

## Motif Architecture

- **Main theme**: hero/identity motif, 3–7 notes, singable, adaptable to
  major/minor, fast/slow, full/sparse.
- **Character motif**: shorter, intervallically distinct (e.g., falling
  minor 3rd + tritone for villain).
- **Transformation rules**: state them — e.g. "hero motif inverts in Act 3
  to signal moral compromise." This is what makes a score feel composed,
  not pastiched.

## Cue Structure (typical 60–180s)

```
FOLEY/ROOM TONE (pre-roll) → SPARSE MOTIF STATEMENT →
LAYER BUILD (add rhythm/pedal) → THEMATIC DEVELOPMENT →
CLIMAX HIT (orchestrated peak at cut point) →
RESOLUTION or BUTTON (short cadence sting)
```

Mark **hit points** explicitly in the timeline: "t=1:22.5 — cut to black,
music hits low cluster + sub drop."

## Orchestration Colors

- **Strings**: legato long tones = emotion; ostinato 16ths = drive;
  col legno/spiccato = texture; divisi = vastness.
- **Brass**: low brass = dread/power; solo horn = nobility; muted = distance.
- **Woodwinds**: flute = air/wonder; clarinet = intrigue; bassoon = comedy/dark.
- **Percussion**: taiko/anvil = epic weight; prepared piano = unease;
  heartbeat tom = dread; metallic FX = futuristic.
- **Hybrid**: orchestra + synth sub, choir + granular textures.

## Trailer & Commercial Grammar

- Trailers: quiet motif → ostinato build → braam/titan hit → resolve.
  Give BPM ramp (e.g., 70→140 feel via subdivision, not literal tempo).
- Commercials: brand motif must land in first 2s and recur as logo sting.
- Documentaries: restraint — often single instrument + field texture;
  earn the one big swell.

## Source Music vs. Score

Decide diegetic vs. non-diegetic and say which. Hybrid cues (source song
that swells into score) need the transition point specified.

## Deliverables per Cue

- Cue number/title, scene description, duration
- Tempo map, key centers per section (modulations marked)
- Instrumentation list with playing techniques
- Full harmonic rhythm (chord per bar minimum)
- Motif usage map: where stated, developed, inverted, fragmented
- Dynamic curve (pp→ff marks with timestamps)
- Mix notes: reverb space, low-end strategy, mono-compat warnings
