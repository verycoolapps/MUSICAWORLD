# Genre Innovation Reference

Load for genre mutation, hybrid styles, and invented genres.

## Genre Literacy First

Before mutating, know the genre's DNA:
- **Classical**: orchestral, baroque, romantic, impressionist,
  minimalist, contemporary.
- **Cinematic**: epic, ambient, hybrid orchestral, suspense, adventure.
- **Electronic**: ambient, IDM, downtempo, synthwave, future garage,
  drum & bass, experimental.
- **Rock**: alternative, progressive, post-rock, symphonic, experimental.
- **Jazz**: modal, fusion, avant-garde, contemporary.
- **World**: study traditions respectfully — understand context, never
  reduce cultures to sonic stereotypes or costume pastiche.
- **Pop**: alternative, art, dream, experimental, electronic.
- **Experimental**: glitch, drone, noise, electroacoustic, spectral,
  microtonal.

## Mutation Protocol

A new genre must define ALL of:

1. **Name** — evocative, not random (e.g., "Hollow Waltz," "Rust Choir").
2. **Philosophy** — one sentence of musical worldview.
3. **Emotional identity** — what it makes listeners feel and why.
4. **Rhythmic characteristics** — meter, tempo range, groove DNA.
5. **Harmonic characteristics** — scale/mode/chord vocabulary.
6. **Instrumentation** — core palette + signature elements.
7. **Production identity** — texture, space, loudness aesthetic.
8. **Vocal characteristics** — if any; delivery style.
9. **Arrangement principles** — typical structure/energy map.
10. **Distinctive signature** — the one thing that makes it recognizable.

## Example Mutations (specimens)

- **"Choir of Machines"** — orchestral percussion + formant-synthesized
  "voice" choir; Phrygian; slow ceremonial pulse; industrial-organic.
- **"Deep Field Waltz"** — 3/4 at 60bpm, sub-bass melody, granular
  textures, no drums; loneliness made elegant.
- **"Static Bloom"** — glitch rhythms quantized to pentatonic grids;
  bright digital textures over warm analog pads; pop hooks in noise.

## Fusion Rules

- Pick 2–3 genres maximum per mutation; more = noise.
- Identify which element comes from each parent (rhythm from A,
  harmony from B, production from C).
- The fusion needs a **resolution rule**: how conflicting elements
  coexist (e.g., jazz harmony over breakbeat rhythm via guide-tone
  substitutions).
- Test: describe the genre to a musician in one sentence — if they
  can predict the sound, the identity is legible.

## World Music Ethics

- Research the tradition's actual theory and context before borrowing.
- Credit inspirations specifically; avoid exoticizing language
  ("mystical," "ancient," "tribal" as lazy shorthand).
- Collaborate/cite when using real traditions; distinguish inspired-by
  from authentic practice.
