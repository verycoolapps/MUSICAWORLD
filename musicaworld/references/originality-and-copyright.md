# Originality & Copyright Reference

Load before any delivery to run the integrity check.

## The Originality Protocol

**Never claim** a sound, melody, instrument, or composition "has never
existed in human history." Demonstrable originality is pursued through:

- Distinctive compositional decisions (document them)
- Original melodic structures
- Unusual sound combinations
- Custom-designed sonic textures
- Unique arrangement concepts
- Independent creative development
- Similarity checks where appropriate

Say "original development" or "original composition." Novelty is a
degree, not a binary.

## Hard Prohibitions

Never intentionally produce:
- Copyrighted melodies (even altered by a few notes)
- Recognizable song arrangements of existing works
- Protected lyrics (quotes, adaptations without license)
- Unlicensed samples or recordings
- Distinctive passages from existing works (riffs, hooks, basslines)
- A living artist's signature sound or voice

## Artist Reference Handling

User says "like [Artist]" → translate to musical characteristics:

| Reference type | Translate to |
|---|---|
| Artist | genre + production aesthetic + instrumentation |
| Song | tempo/meter/key + instrumentation + vocal style |
| Genre | genre conventions + era production traits |
| Mood | emotional map + tempo + timbre palette |

Output general characteristics only — never reproduce a signature
melody, lyric, or production fingerprint.

## Similarity Sanity Check

Before delivery, self-check:
1. Does the hook resemble a famous melody? Test by singing it flat —
   does it trigger recognition?
2. Does the chord progression + rhythm match a well-known song skeleton?
   Progressions alone aren't copyrightable, but progressions + melody +
   rhythm together can be.
3. Are lyrics original text? No quotes, no paraphrased famous lines.
4. Any sample-like elements? Must be synthesized/original.

If similarity risk appears: change the motif contour, reharmonize,
shift rhythmic placement. Document what changed.

## Encouraged Practices

- Original melodies and independent arrangements — always.
- Licensed samples with attribution when user supplies them.
- Public domain / CC0 material when user requests vintage textures.
- Provenance documentation: keep notes on what was invented vs.
  referenced, useful for commercial disputes.
- Commercial-use verification: remind users that AI-generated output
  copyright status varies by platform and jurisdiction; for commercial
  release, verify the generation platform's terms.

## Legal Honesty

Never guarantee copyright clearance or legal originality. State:
"This is an original composition developed independently. Final
copyright status depends on your jurisdiction and the tools used to
produce the audio."
